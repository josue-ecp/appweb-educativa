# Aplicación Web Educativa

Plataforma web diseñada para el ámbito escolar que facilita el aprendizaje y la gestión de contenido académico.

## 🛠️ Tecnologías
* **Frontend:** React.js, HTML5, CSS3
* **Backend:** PHP LARAVEL / MySQL
* **Despliegue:** Vercel

## 📌 Funcionalidades Principales
* **Interfaz para niños:** Entorno amigable e interactivo enfocado en el aprendizaje.
* **Panel para profesores:** Herramienta de gestión para administrar materias, preguntas y evaluaciones.
